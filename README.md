# haltech-log-trimmer
Haltech log trimmer for VirtualDyno pulls. Automatically selects the pull window and exports a VD log format. 

Boost is calculated from MAP and clamped to be not less than 0.

Note: the logs will load as "Nismotronic" logs. That's okay, it'll work fine.
For Boost/AFR display, go to File->Options, then "Columns and Profiles" and set "AFR" column name to "AFR" and "Boost" column name to "Boost"
